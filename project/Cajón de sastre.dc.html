1Kit inyectado
El lanzador antepone cajon-kit.css al HTML de cada app y cambia data-theme al cambiar de tema. Las apps usan variables, nunca colores fijos.
:root, [data-theme="light"] { --bg: #F5EEE3; --surface: #FBF7F0; --text: #4A3F35; --accent: #8A5A44; --peach: oklch(0.88 0.06 55); --peach-ink: oklch(0.38 0.08 55); --r-card: 24px; --font: 'Nunito'; } [data-theme="dark"] { --bg: #2B241F; --surface: #382F28; --text: #F3E9DB; --accent: #E9C9A6; --peach: oklch(0.76 0.045 55); … }
.tarjeta { background: var(--surface, #FBF7F0); border-radius: var(--r-card, 24px); box-shadow: var(--shadow, 0 8px 24px #0001); }

2Prompt base para crear apps
Se pega al principio de cada petición. Las apps nacen con las variables, los radios, los iconos de línea y el modo móvil ya resueltos.
Crea una mini-app en UN solo archivo HTML. Va dentro de «Cajón de sastre», que le inyecta variables CSS. • No uses colores fijos: usa var(--bg), --surface, --text, --accent y los pasteles --rose, --sage, --lav, --peach, --sky, --butter, --mint, --clay (+ -ink). • Fuente var(--font); radios --r-card; botones en píldora; sombras suaves --shadow; sin bordes duros. • Funciona en claro y oscuro solo con las variables. • Iconos SVG de línea, trazo 1.6, currentColor.
